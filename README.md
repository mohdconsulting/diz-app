# MOHD Consulting AB – hemsida

Statisk, responsiv webbplats på svenska (ingen build, inga cookies, ingen spårning).

- `index.html` – innehåll
- `styles.css` – design (ljust/mörkt läge, mobilanpassad)
- `favicon.svg`

Förhandsgranska: öppna `index.html` i en webbläsare, eller `python3 -m http.server`.
Publicera: valfri statisk hosting (Netlify, GitHub Pages, Cloudflare Pages) – ladda upp mappens innehåll.

**Att göra innan lansering:** byt e-postadressen `kontakt@mohdconsulting.se` i `index.html` (sektionen Kontakt) till bolagets riktiga adress och lägg gärna till organisationsnummer i sidfoten.
